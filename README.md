# ARCHI-TACT משרד

ניהול משרד אדריכלות: שלבים, אישורי לקוח, דרישות תשלום ותזרים. מהשלב, דרך אישור הלקוח, אל התשלום.

כתובת: https://misrad.vercel.app

## הרצה
```
npm install
npm run dev        # פיתוח
npm run build      # בדיקת טיפוסים ובנייה
npm test           # Playwright מול vite preview (אחרי build)
```

## מבנה
- `src/domain`: מודל הנתונים (`types.ts`), מכונת המצבים של שלב, סיכונים, תזרים ומדדי אמינות (`logic.ts`), קישורי פורטל (`share.ts`), נתוני הדגמה ותבנית שלבים (`seed.ts`).
- `src/store/store.tsx`: מקור נתונים אחד, שמירה ב-localStorage בכל שינוי, מצב עריכה והודעות.
- `src/components`: הסרגל העליון וכפתור הלוגו A&I, רכיבי ממשק, ויזואליזציות (מסילת שכר הטרחה, צינור בנייה-גשר-תשלום, תזרים, גיול, טבעת).
- `src/pages`: בית, משרד, פרויקט, תזרים, דרישת תשלום, פרויקט חדש, הגדרות, פורטלים.
- `tests/e2e.mjs`: בדיקת קצה לקצה.
- `docs/SPEC.md`: האפיון.

## החלטות
- בלי שרת בשלב הזה: הנתונים במכשיר, עם ייצוא וטעינת גיבוי. קישורי הלקוח והקבלן נושאים תמונת מצב דחוסה בכתובת עצמה (`#`), כך ששום מידע לא עובר דרך שרת.
- אישור לקוח חוזר לסטודיו עם קוד ביקורת (FNV), שמונע טעויות העתקה ובלבול בין שלבים.
- כל סכום וכל סיכון נגזרים מהנתונים. אין מספרים קשיחים בממשק.
